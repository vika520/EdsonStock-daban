# EdsonStock-daban · A股超短游资实时信号与脉冲推送工作台

> **四层量化架构 + 每日 Top 10 自动选股引擎 + 腾讯 L1 实盘五档盘口直连 + 东财三池 `curl` 防封 + A 股 T+1 无偏差回测 + 飞牛 NAS Docker 一键部署**

## 一、 核心架构与功能模块

1. **四维游资量化每日自动选股 (`scripts/auto_pick_top10.py`)**
   - **情绪周期动态配额**：读取 `edsonstock-data` 的 `sentiment` 快照与当日跌停家数；冰点/退潮期（涨停<35 或 跌停>15）将 >=4 板高标配额归零，改选 **1进2 首板 + 首阴回踩 5 日线**；主升期把主线卡位组从 3 席扩到 5 席；
   - **联合评分**：封成比 + **封流比(封单/流通市值)×8**，换手率 8%~28% 黄金区 +15 分，<3% 缩量一字 / >40% 死亡换手扣分；
   - **龙虎榜负面席位否决**：买榜 >=3 个拉萨散户席位且卖榜净卖出 -> 一票否决剔除；买榜 >=2 量化席位且买卖双边同现 -> 扣 30 分并打 `【量化做T预警】`；买一占总成交 >15% -> `【独食板预警】`；
   - **9:25 真弱转强**：仅在竞价窗口内，同时满足高开 +1.0%~+7.5% 且 **竞价成交额/昨日全天成交额 5%~18%** 才标记 `【9:25真弱转强】` 并置顶；
   - **调度时点（北京时间）**：`live_signal_server.py` 后台线程在 **09:25** 竞价重排、**09:35 / 09:45** 早盘卡位替补（剔除开盘 <= -3% 弱势股，补入 09:30~09:40 首封且封流比 >2% 的主线卡位股）、**15:05 / 17:35** 盘后选股，自动更新 `web/daily_picks.json`。

2. **盘中实时五档盘口与主动放量工作台 (`web/index.html`)**
   - 原生动态 `<script src="https://qt.gtimg.cn/q=...">` 实时行情直连，每 2~3 秒刷新监控池全部标的的**真实五档委托队列、实时量比、换手率、外盘-内盘主动买差（+万手）、买一封单额与封成比**；
   - **前后秒真实盘口差分引擎 (Real Diff Engine)**：自动捕捉 3 秒内突发爆量点火（`ΔvolHand >= 3000手`）及涨停板买一封单撤单预警；
   - 支持在页面顶部输入框直接添加任意 6 位 A 股代码实时盯盘。

3. **A 股真实微观规则约束回测 (`scripts/ashare_backtest.py`)**
   - 强制执行 **T+1 交收**、主板/双创/北交/ST 差异化涨跌停阈值、**一字涨停排单失败拦截**、**一字跌停锁仓延迟卖出**、真实印花税佣金滑点扣除，以及滚动窗口无未来函数 + 区间首次进入去重的单侧 `p-value` 因果检验；
   - 内置 `weak_to_strong`（首板/试盘次日 9:25 竞价弱转强 1进2 接力）、`first_pullback`（涨停基因首次缩量回踩 5 日线）、`mean_revert`、`breakout`、`ma_cross` 五大策略。

## 二、 飞牛 NAS Docker 一键部署

部署脚本已移到 `ops/`，连接参数从 `ops/.env` 读取（该文件不会提交）：

```bash
cp ops/.env.example ops/.env
# 编辑 ops/.env，填写 NAS_HOST / NAS_USER / NAS_DIR / PORT
bash ops/deploy_to_nas.sh
```

部署完成后直接访问（`<NAS_HOST>` 为 `ops/.env` 中填写的地址）：
- **超短实盘信号工作台**：`http://<NAS_HOST>:8899/`
- **每日 Top 10 自动选股接口**：`http://<NAS_HOST>:8899/api/daily_picks`（手动重选：`?refresh=1&mode=post|auction`）
- **腾讯五档与放量实时接口**：`http://<NAS_HOST>:8899/api/quotes?codes=603324,002771,002164`
- **东财涨跌停/炸板实时三池**：`http://<NAS_HOST>:8899/api/zt_pool`

## 三、 GitHub Actions 自动更新（Cloudflare Pages 静态站适用）

`.github/workflows/daily-picks.yml` 会在交易日自动运行选股脚本并把结果写回 `web/daily_picks.json`：

- 北京时间 **09:25**（竞价重排）、**15:05**（盘后初选）、**17:35**（龙虎榜终选）；
- 也可在 GitHub 仓库 Actions 页面手动运行，选择 `post` 或 `auction` 模式；
- 结果校验失败（例如网络异常导致涨停池为空）时保留原文件，不会用空数据覆盖；
- 文件提交到 `main` 后会触发 Cloudflare Pages 自动重新部署。

## 四、 数据口径与已知局限

- **情绪快照**：来自 `vika520/Edsonstock` 的 `extras.json → sentiment.snapshot`，为盘后公开的 T+1 数据，非实时；`cycle.dataReady=false` 表示当日三池尚未生成，周期判定只依赖快照。
- **昨日全天成交额**：腾讯日 K 只提供成交量(手)，`prevDayAmountEstYi` 由「成交量 × 100 × 当日 OHLC 均价」推算，是**量价代理，不是真实成交额**；因此 `auctionVolRatio` 的 5%~18% 阈值应按代理口径校准。**按日期锚定**（取「日期 < 今日」的最后一行），不依赖日 K 末行是谁——腾讯当日行插入时间不稳定，盘后也可能尚未插入。
- **龙虎榜日期锁**：`lhbDate != tradeDate` 时（如 15:05 当日榜未披露）`lhbLocked=false`，**不使用龙虎榜做任何加减分**，龙虎榜组席位为空，Top 10 可能少于 10 只（宁缺毋滥）。17:35 当日榜披露后恢复。
- **龙虎榜穿透范围**：净买前 30 + 净卖后 10 + 跌停/炸板池代码，取满买卖各前 5 席；「拉萨 ≥3 席且卖榜净卖出」一票否决对陷阱股同样生效。
- **北交所排除**：主线卡位池排除 92/8/4 开头（30% 涨跌幅 + 流动性薄，1 板卡位逻辑适用性差）；高标/龙虎榜组不排除。
- **竞价窗口守卫**：`auction` 模式仅在北京时间 09:15~09:40 之间启用真弱转强标记与置顶；其余时段腾讯成交额非竞价口径，只写字段不重排（`auctionNote` 会说明）。
- **09:35/09:45 替补**：仅从「当日 09:30~09:40 首封 + 主线板块 + 封流比>2%」的候选中补位；若合格候选不足，Top 10 会少于 10 只（宁缺毋滥），且不会把已剔除的弱势股补回。**此为盘后/复盘参考，不是盘中买点**——09:35 时好板已排队无望。
- **空结果保护**：`run_auto_picker` 在结果 `< 3 只` 或 `ok=false` 时**不覆盖**已有 `daily_picks.json`，与 CI 校验一致。
- **前端时间判定**：统一用 `bjClock()` 按 UTC+8 计算，不依赖浏览器本地时区（已在 5 个时区下验证）。
- **买一撤单识别**：`cancelEst = max(0, -(bidDiff + deltaHands))`，扣除被成交吃掉的部分后才是真撤单；原先直接用 `bidDiff` 会把大单成交误报为撤单。
- **跨仓库依赖**：`fetch_workbench.py`（需 `tdx_direct`）与 `fetch_extras.py` 的现货基差功能（需 `daily_update`）依赖上游 `vika520/Edsonstock` 主仓库，本仓库未包含，运行时会给出明确提示而非 ImportError 崩溃；读已落盘数据请用 `scripts/query.py --what workbench`，本地读取用 `--local <dir>`。
- **规则性质**：上述配额、评分权重与阈值均为**启发式规则，未经本仓库回测框架验证**，不构成「高胜率」的统计证据；`scripts/ashare_backtest.py` 的回测口径与选股规则相互独立，请勿把回测结论直接套用到本选股结果。
