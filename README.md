# EdsonStock-daban · A股超短游资实时信号与脉冲推送工作台

> **四层量化架构 + 每日 Top 10 自动选股引擎 + 腾讯 L1 实盘五档盘口直连 + 东财三池 `curl` 防封 + A 股 T+1 无偏差回测 + 飞牛 NAS Docker 一键部署**

## 一、 核心架构与功能模块

1. **四维游资量化每日自动选股 (`scripts/auto_pick_top10.py`)**
   - **空间高标组 (2只)**：全市场最高连板身位（$\ge 3$ 板），按连板数 + 封成比 + 首封时间排序；
   - **主线 1进2 / 2进3 卡位组 (3只)**：当日涨停家数 TOP 3 主线行业中，高封成比、早盘秒板、换手率健康的晋级先锋；
   - **龙虎榜游资/北向/机构合力组 (3只)**：东财最新龙虎榜大额净买入，且买榜出现知名游资（章盟主、方新侠、六一中路、呼家楼等）、北向或机构专用协同锁仓；
   - **高分歧回封/炸板风控观察组 (2只)**：大成交分歧烂板或炸板池核心辨识度股，作为次日 9:25 观察「弱转强反包」或「核按钮风控」的锚点。
   - **双时点自动调度**：`live_signal_server.py` 内置后台定时线程，每个交易日 **15:05 / 17:35 盘后选股**、次日 **09:25:05 集合竞价弱转强动态重排**，自动更新 `web/daily_picks.json`。

2. **盘中实时五档盘口与主动放量工作台 (`web/index.html`)**
   - 原生动态 `<script src="https://qt.gtimg.cn/q=...">` 实时行情直连，每 2~3 秒刷新监控池全部标的的**真实五档委托队列、实时量比、换手率、外盘-内盘主动买差（+万手）、买一封单额与封成比**；
   - **前后秒真实盘口差分引擎 (Real Diff Engine)**：自动捕捉 3 秒内突发爆量点火（`ΔvolHand >= 3000手`）及涨停板买一封单撤单预警；
   - 支持在页面顶部输入框直接添加任意 6 位 A 股代码实时盯盘。

3. **A 股真实微观规则约束回测 (`scripts/ashare_backtest.py`)**
   - 强制执行 **T+1 交收**、主板/双创/北交/ST 差异化涨跌停阈值、**一字涨停排单失败拦截**、**一字跌停锁仓延迟卖出**、真实印花税佣金滑点扣除，以及滚动窗口无未来函数 + 区间首次进入去重的单侧 `p-value` 因果检验；
   - 内置 `weak_to_strong`（首板/试盘次日 9:25 竞价弱转强 1进2 接力）、`first_pullback`（涨停基因首次缩量回踩 5 日线）、`mean_revert`、`breakout`、`ma_cross` 五大策略。

